# Emissor de Notas Fiscais Rápido — atualizações

Repositório de distribuição da **M² TECH**.

- **Instalador mais recente:** pasta [`instaladores/`](instaladores/) (Windows 10/11, 64 bits).
- O programa consulta o arquivo [`atualizacao.json`](atualizacao.json) e, quando há versão nova,
  oferece "Atualizar agora": baixa o instalador, confere o SHA-256 e instala sozinho.
- Não apague nem renomeie `atualizacao.json`.

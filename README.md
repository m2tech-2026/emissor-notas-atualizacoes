# Emissor de Notas Fiscais Rápido — atualizações

Repositório de distribuição da **M² TECH**. O programa consulta o arquivo `atualizacao.json`
deste repositório e, quando há versão nova, baixa o instalador da página **Releases**.

- Instalador mais recente: veja **Releases** (à direita).
- Não apague nem renomeie `atualizacao.json`.
